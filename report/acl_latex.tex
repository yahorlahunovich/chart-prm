\begin{abstract}
Multimodal Large Language Models (MLLMs) frequently struggle with fine-grained chart reasoning due to compounded visual perception errors, misaligned axis readings, and flawed intermediate arithmetic. Standard outcome-based supervision provides sparse feedback that fails to locate where a reasoning chain diverges. In this work, we investigate Process Reward Models (PRMs) and step-level preference optimization techniques for chart question answering. Using a stratified reasoning subset of 500 scientific charts from the CharXiv benchmark, we generate multi-step reasoning rollouts using \texttt{Qwen2.5-VL-3B-Instruct} and grade each step using a multimodal LLM-as-a-judge (\texttt{muse-spark-1.1}). We analyze step-level error propagation, categorize judge text critiques into a 9-category error taxonomy, and benchmark three alignment methods under strict compute constraints: Step-DPO, KTO, and SFT.
\end{abstract}
